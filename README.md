## 💼 Currently building: Articulate

Backend for [**Articulate: Vocabulary Mastery App**](https://apps.apple.com/app/id6759561001), a vocabulary-learning app live on the App Store, with Android on the way.

- Python / **FastAPI** microservices on **AWS ECS**, backed by **PostgreSQL (RDS)** behind an Application Load Balancer.
- Push notifications with **Firebase Cloud Messaging**, scheduled per user time zone, plus a day-streak system with streak freezes.
- **App Store** and **Google Play** subscriptions, verified server-side and kept in sync through store webhooks.
- CI/CD with **GitHub Actions**: lint, tests and automatic deploys to ECS.
